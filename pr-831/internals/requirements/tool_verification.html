Doc-as-Code Tool Verification Report#

This page is the authoritative Tool Verification Report for the S-CORE Docs-as-Code tool. It records the classification of intended usage, potential malfunctions, safety impact and detection, together with qualification evidence and lifecycle state.

Tool under evaluation#

The S-CORE Docs-as-Code tool (Bazel module score_docs_as_code) builds HTML documentation and traceability data from RST/Markdown sources. It evaluates those sources with the S-CORE extensions and metamodel, and produces the generated documentation, needs.json and metrics.json used by the downstream process.
